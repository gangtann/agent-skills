# 在抖音桌面客户端发布

只有用户明确说"发布"才执行。发布是公开且不可撤回的操作，用户点名要发哪条视频才算授权。用户说「最好发成草稿」时，填完后点「暂存离开」存草稿，等用户再说「发布」才点「发布」。

## 先准备好的内容

- **视频**：`~/Desktop/抖音配音素材/NN_中文名/<名>_成片.mp4`（finalize.sh 生成的 1080p 成片）
- **封面**：同目录的 `<名>_封面.png`（横屏视频是 1440×1080，4:3；竖屏旧片是 1080×1440，3:4）。横屏视频另备 `<名>_竖封面.png`（1080×1440，`node rec.js cover34`）
- **作品标题**（≤30 字）：一个戳心的问题或反差，通常就是封面上的大标题。例：「凌晨两点，你在舍不得什么？」
- **作品简介**：一句钩子，一行「数据来源：机构 A、机构 B、论文作者 年份 等。」（画面上已经不放出处，简介里要有），后面接 4–6 个话题。例：「夜里偷回来的时间，被谁拿走了？ #报复性熬夜 #熬夜 #睡眠 #打工人 #纪录片」。话题选法：1 个主题词 + 2 个上位大词 + 1 个人群词 + 1 个形式词（#纪录片 / #知识）
- 不加 AI 声明（「自主声明」留空），不 @ 任何人，不提原作者或参考账号

## 操作步骤（computer use，App：抖音 com.bytedance.douyin.desktop）

1. `open_application 抖音`，等首页加载出来（刚打开时窗口是空白，要等几秒）。如果 VS Code 等未授权的 App 挡在前面，再 `open_application 抖音` 一次把它带到前台。
2. 点右上角「投稿」图标（在 通知/消息 旁边）。这会打开一个**独立的「抖音创作者中心」窗口**，后面的操作都在这个窗口里。
3. 左上「作品发布」→ 发布视频 → 点「上传视频」打开系统文件框 → `cmd+shift+g` → 输入成片的完整路径 → 回车 → 回车。上传 200MB 左右要 40 秒到 1 分钟，可以边传边填。
4. **作品描述**：点标题框输入标题；点下面的简介框输入简介。多行简介要一行一行输入、行间按回车；整段带换行的文本会走剪贴板粘贴，实测没有粘进去。话题要逐个输入：先输入 `#报复性熬夜`，等下拉建议出现，**点第一条建议**，它会变成蓝色的话题块；再输入下一个。直接打空格不一定能变成话题。
5. **设置封面**：横屏视频点「横封面4:3」的「选择封面」（竖屏视频点「竖封面3:4」）→ 弹窗里点「上传封面」→ 文件框 `cmd+shift+g` 输入封面路径 → 回车 → 回车。
   - **坑**：创作者中心窗口太矮，弹窗底部的「完成」按钮被截掉，点不到（按坐标或用元素序号点，都会落在外层容器上）。先用 `app_menu 窗口 → 填充` 把窗口放大，再点「完成」。
   - 竖屏视频点完成后会弹出「设置横封面获更多流量」，选「暂不设置」，抖音会自动生成横封面。
   - **横屏视频**：横封面点完成后，抖音会自动「基于横封面生成竖封面」，但会切掉标题（「报复性熬夜」横屏版的「夜」字被切了）。要把鼠标移到「竖封面3:4」缩略图上，点「编辑封面」→「上传封面」→ 上传 `<名>_竖封面.png` → 完成。看到「封面效果检测通过」就好。以实际界面为准，有变化就更新这一段。
   - 「官方活动」卡片在鼠标悬停时会高亮，不代表已经添加。不要点「+添加」。
6. 往下滚：「添加合集」「自主声明」都留空；「发布设置」保持 谁可以看 = 公开、保存权限 = 允许、发布时间 = 立即发布。
7. **存草稿**：点「发布」旁边的「暂存离开」。之后再打开投稿页，会出现「你还有上次未发布的视频，是否继续编辑？ 继续编辑 / 放弃」，点「继续编辑」就能回到草稿，标题、简介、话题和封面都还在。**不要点「放弃」**，它会删掉草稿。
   **发布**：点「发布」，会显示「正在发布」，页面跳到「内容管理」。新作品要**刷新页面**（窗口左上角的刷新图标）才会出现，状态先是「审核中」，通常几分钟到一小时后变成「已发布」。
8. 结束后 `app_release`，告诉用户：标题、简介和话题、封面、发布时间、当前审核状态。

## 用 app_* 还是全屏工具

- 在主窗口点「投稿」、在文件框里输路径，用全屏的 `computer_batch`（截图 → 点击 → 按键）。系统文件框是原生 sheet，后台的 app_click 和 app_key 都送不进去，必须用全屏工具（会弹一次全屏授权）。
- 右侧「发文助手」的「作品检测失败：当前检测人数过多」只是可选的快速检测没跑成，不影响发布。
- 进入创作者中心以后，用 `app_screenshot`、`app_click`、`app_scroll`、`app_menu` 在后台操作更稳。用 `app_list_windows` 找标题为「抖音」且 is_main 的那个窗口 id。
- 两套工具不能在同一轮里混用。从 app_* 切回全屏工具之前，先 `app_release`。
