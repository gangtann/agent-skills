## 1. 画布与安全区

**默认横屏 1920×1080，30fps**（用户 2026-10-14 要求；`format.json` = landscape）。

- 抖音横屏 UI 遮挡（全屏播放时）：顶部 0–76（左上搜索栏）、底部 870–1080（作者名、标题文案、进度条，约 20%）、右侧按钮列约 x 1780–1920 × y 260–870。
- **画面文字只放在 x 140–1700、y 90–760。** 标题、数字、引语都在这个框里。
- **字幕固定在 y≈784**，单行，宽 1300（left 310），52px 苹方，带描边阴影；main.js 把长句按标点切成 ≤20 字的段。字幕和画面文字是两套系统，互不替代。
- 横屏视频在手机竖着刷时会缩到屏幕宽，字会变小：正文不小于 40px，小字不小于 28px，大标题 88px 起。
- 构图：左右三分。人物/主体放一侧，文字放另一侧并用 `scrimX` 侧向压暗；片名、金句可以居中。3D 城市横向铺满，天际线放在画面 45–60% 高度。
- 封面 1440×1080（4:3），大标题 ≥120px、两行以内，放左侧。

竖屏（`format.json` = portrait，只在用户点名时用）：1080×1920；遮挡区顶部 0–288、底部 1440–1920、右侧 x 930–1080 × y 860–1440；文字 x 72–900、y 300–1240；字幕 y≈1312、42px、≤17 字；封面裁 3:4。「报复性熬夜」是竖屏做的。
「AI 会不会抢走工作」（2026.10）把字幕放在约 67% 高度，被抖音的文案区和按钮挡住了，这是定安全区的起因。
- 单屏文字 ≤2 行或约 20 字。画面要留白，主体占比克制。

## 2. 色彩、字体、文字样式

色板（lib.js 的 `C`）：night #05080f · deep #0b1424 · navy #12213a · blue #3a5a8a · cold #9cbce6 · ice #d7e6fa · **amber #ffb35a（数据重点）** · warm #ff8c42 · ember #e2572b · text #eef2f7 · mute #8b95a8。
基调是深夜冷蓝底 + 屏幕/灯光暖色点缀；最后一章（出路）整体转暖。换题材时可以换主色，但全片只用一套，并在分镜脚本的「视觉系统」里写明。

字体：标题/金句 Songti SC（宋体 900/700），正文 PingFang SC，数字 DIN Alternate。三种，不再加。

film.html 里的文字类（txt 的 `c`）：

| 类 | 用途 | 规格 |
|---|---|---|
| k | 小标题/kicker | 苹方 600 28px，琥珀，字距 7 |
| h | 大标题 | 宋体 900 88px |
| h2 | 二级标题、章节名 | 宋体 900 64px |
| q | 引语、金句 | 宋体 700 58px |
| n / n2 / n3 | 大数字 / 中数字 / 小数字 | DIN 176 / 104 / 64px，n、n2 琥珀 |
| b / b2 | 正文 / 次要正文 | 苹方 40 / 32px |
| s | 小字 | 苹方 28px 灰（**不要用来放出处**：用户 2026-10-14 要求画面上不放出处小字，出处写进 04_数据核实记录.md） |
| en | 英文术语 | DIN 30px 冷蓝 |
| am / co | 行内强调色 | 琥珀 / 冷蓝 |

动效：文字统一"上浮 22px + 去模糊"入场 0.8s，`at:[句号, 偏移]` 跟着旁白出现，`out` 退场。镜头间默认黑场叠化（fadeIn .55 / fadeOut .5），需要节奏时用 cutIn/cutOut 硬切。全片叠胶片颗粒 .045 + 暗角。

## 3. 镜头语言：可用的场景类型

每一帧都要有明确主体 + 光影 + 信息。参考 examples/revenge_sleep/shots.js 里的实现：

- **人物剪影 + 轮廓光**（`lit()`）：侧脸特写被手机屏幕光照亮（S01/S25 卧室）；屏幕光用 `screenCol(t)` 四色轮换。不要画卡通形状的人，要用真实比例的侧脸轮廓（headPath）。
- **3D 城市**（`gl:'night'|'title'|'tower'|'dawn'`）：摇臂升空、环绕片名、仰拍写字楼、黎明横移。
- **数据可视化**：数字滚动（txt 的 `fn`）、条形生长、环形图、折线、对比光柱。数据跟着念到它的那句旁白出现。口径（期别、人群、对照组）写进数字旁的正文，例如「企业员工 · 2026 年 8 月」，不写来源机构。
- **意象场景**：时钟特写、医院走廊一点透视、地铁车厢多层视差、锁屏通知堆叠、城中村窄巷、整面亮灯的大楼推近、台灯书桌浅景深。
- **章节卡**（`chapter(n, 标题, warm, bg)`）：编号 + 宋体标题 + 一条生长的线，2.2 秒。**用实拍素材做 bg**；不给 bg 时退回光斑背景，那就是「空背景 + 一行字」（「报复性熬夜」的 5 张章节卡覆盖率只有 0.07–0.10）。
- **实拍空镜**（`vid`）：真实场景优先用实拍打底，见 references/footage.md。
- **结尾**：回到开头的构图（首尾呼应）→ 金句 → 互动问题（"评论区，说说你的答案"）。默认不加资料来源页（`build_timeline.py --src` 才加）。
- 运镜：`cam(ctx, s, cx, cy, dx, dy)` 做推拉移；多层不同速度做视差；`bokeh` 做景深光斑；每个镜头至少有一种运动。

## 4. 3D 城市（city.js）

程序生成的盒子楼群，窗户是 CanvasTexture 做 emissiveMap，点精灵做路灯和车流，ACES 色调映射。`City.render(mode, lt, p, o)`：
- night：从街面摇臂升到高空；`glo:{win}` 调窗光强度
- title：高空环绕
- tower：街道里仰拍写字楼（窗全亮）
- dawn：天色由蓝转暖、窗灯熄灭

## 5. 已踩过的坑

- **雾太浓**，高空看不到城市 → 夜景雾密度随升空从 .0016 降到 .00055。
- **墙面发蓝光**：窗户贴图的底色不是纯黑 → 底色 #000，未亮窗 #020306。
- **天际线有一条色带** → 背景色 = 雾色（`setBg`），再叠 2D 的 `skyTop` 渐隐。
- **仰拍时出现条纹和漂浮白块**：相机贴着楼、离车灯点太近 → 相机放在街道中间（85, 5, 210），tower 模式隐藏车和路灯。
- **开头钩子像卡通**：第一版是一团圆形 → 改成真实比例的侧脸特写 + 轮廓光；画中的钟不能被画面左边缘切掉。
- **压暗带有硬边** → `scrim` 先实色填到画面边缘，再接渐变。
- **文字压在亮窗上看不清**：推近大楼时上方压暗带随推近消失 → 文字出现时单独再压一层 `scrim(.., .93*on)`。
- **转场尾部是空画面**：镜头最后一句说完后还有 1 秒推近，抽帧正好落在这里 → 给长推近的结尾留一句画面文字（如 S22 的「最后一块 / 只属于自己的时间」）。
- **元素重叠**：走廊灯压在引语上、引语跨过门框、车厢光晕成团、字幕压在亮窗上 → 每次改完都用 `rec.js shots` 出联系表逐镜检查。
- **封面**：手机边缘线穿过标题 → 整个场景下移 190px 再裁 3:4（竖屏工程）。
- **横屏城市露边**：同样的相机在横屏里水平视角宽很多，楼群网格的边缘进了画面 → 横屏下城市铺大（N=40），fov 乘 0.72。
- **码率**：颗粒让 crf 17 的母带到 33Mbps。成片用 `hqdn3d` 轻降噪 + crf 21（4 分钟约 200MB）；发给用户看用 720p 版（约 20–40MB）。
